🐬 Spotweb connection

Used to fetch the NZB behind a pasted spot link.
Found in Spotweb under your own profile / account settings ("Gebruiker wijzigen"). Users can set their own personal key on their Account page, which takes priority over this one — set this so Flipper works before anyone has done that.
{base}, {messageid} and {apikey} are substituted. The default uses Spotweb's built-in Newznab-compatible API ({base}/api?t=get&id={messageid}&apikey={apikey}) — the same mechanism tools like Sonarr/NZBHydra use, no session login required. Only change this if your instance is customized.
Only fill these in if something sits in front of Spotweb itself (e.g. an nginx/Cloudflare Access layer) that requires HTTP basic auth. This is separate from — and not a substitute for — the Spotweb API key above.
